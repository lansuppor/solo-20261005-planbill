# planbill

离线按量月结命令行工具（Go 标准库实现，无第三方依赖）。在本地完成客户登记、
用量文件导入、单客户按月结算（封账）与账单查询。各命令顺序运行，数据通过单个
JSON 文件跨进程保存，不依赖任何外部服务或数据库。

需要 Go 1.24 或更新版本。

## 运行方式

```sh
go run .                 # 无参数：显示帮助
go run . --help          # 或 -h
```

数据目录通过 `--data-dir` 指定，也可用 `PLANBILL_DATA_DIR` 环境变量；
默认在当前目录的 `.planbill/`。数据以 `data.json` 保存，采用临时文件写完再
原子替换，命令成功即已完整落盘。

```sh
go run . --data-dir ./mydata register c1 示例客户 100
PLANBILL_DATA_DIR=./mydata go run . import usage.jsonl
go run . --data-dir ./mydata settle c1 2026-01
go run . --data-dir ./mydata bill c1 2026-01
```

## 命令

### register —— 登记客户

```sh
go run . register <客户标识> <客户名称> <单价(分)>
```

- 客户标识全局唯一、非空；名称非空；重复标识、空标识、空名称会被拒绝。
- 单价为**非负整数分**（int64），创建后不可修改（程序不提供修改入口）。
- 失败时不会写入，原有客户与数据保持不变。

### import —— 整批导入用量

```sh
go run . import <用量文件>
```

**文件格式：JSONL（NDJSON），每行一个独立的 JSON 对象，空行忽略。**
每行字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
 `id` | string | 全局唯一用量标识，非空 |
| `customer` | string | 客户标识，必须已登记 |
| `time` | string | RFC3339 时间，如 `2026-01-15T08:30:00+08:00` |
| `quantity` | 整数 | 正整数（int64），不支持小数 |

示例 `usage.jsonl`：

```
{"id":"u1","customer":"c1","time":"2026-01-15T08:30:00+08:00","quantity":10}
{"id":"u2","customer":"c1","time":"2026-01-31T16:00:00Z","quantity":5}
{"id":"u3","customer":"c1","time":"2026-02-01T00:00:00Z","quantity":7}
```

字段名必须严格为 `id` / `customer` / `time` / `quantity`，多写或拼错字段名
（如 `customerId`）按格式错误处理。任何一行出错都会使**整批失败**。

整批规则：

- **先校验、再生效**：客户不存在、JSON 格式错误、字段缺失、时间非法、
  正整数不满足、同标识内容冲突或运算溢出，都会使整批失败，不留下任何新用量。
- 已存在的用量标识按 **(客户, 解析后的 UTC 时间点, 数量)** 判定：
  内容完全相同视为重复并跳过；内容不同则整批拒绝并指出行号与双方内容。
  文件内重复遵循相同规则。
- 时间统一按解析后的 **UTC 时间点**比较：`2026-01-31T16:00:00Z` 与
  `2026-01-31T16:00:00+00:00` 被视为同一时间点（重复）；落库时间规范化为 UTC。
- 金额校验为整数运算 `数量 × 单价`，不使用浮点数；溢出则整批失败。
- 成功时输出新增、重复跳过条数。

### settle —— 单客户月结（封账）

```sh
go run . settle <客户标识> <YYYY-MM>
```

- 按 **UTC 自然月**的左闭右开区间 `[当月1日 00:00 UTC, 下月1日 00:00 UTC)`
  归集该客户用量，以 `数量 × 固定单价` 生成**一张**账单。
- 客户不存在、月份格式无效、该月无用量或总数量/总金额溢出 int64 时，
  拒绝且**不封账**。
- 成功后该客户该月**封账**：之后新用量（不同内容）不得进入该月，导入会被整批
  拒绝；但已入账记录的相同重放仍可成功（算重复跳过）。
- **再次结算**同一客户月份返回**原账单**（稳定账单标识 `B000001` 起），
  不产生新账单、不重新计费；其他客户与月份不受影响。
- 账单与封账状态在同一数据快照中一起持久化，成功只在完整保存后报告。

### bill —— 账单查询

```sh
go run . bill <客户标识> <YYYY-MM>
```

展示稳定账单标识、客户、UTC 月份、总数量、单价、总金额，以及每条用量的
标识、时间、数量和小计，使每笔费用可追溯。客户不存在、月份无效或尚未结算时
非零退出并说明原因。

## 安全与持久化保证

- 所有金额、数量运算使用有符号 64 位整数，无浮点；溢出即失败，不产生错误账单。
- 每次写入先写带 fsync 的临时文件，再 rename 原子替换，并 fsync 数据目录；
  创建、导入或结算失败均保持原业务状态。
- 数据文件损坏或不可读取（空文件、JSON 错误、尾部多余数据、版本不符、
  引用完整性异常等）会报错退出，**不会**被当作空库覆盖。

## 退出码

- `0`：成功，或无参数 / `--help` / `-h`。
- `2`：非法命令、参数错误或业务拒绝（原因输出到标准错误）。
